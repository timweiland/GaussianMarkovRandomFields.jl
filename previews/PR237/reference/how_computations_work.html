How computations work ​

A GMRF is defined by its mean μ and its sparse precision matrix Q. Every quantity the package computes reduces to a handful of operations with Q. With a direct solver, which is the default, they all build on a sparse Cholesky factorization Q=LL⊤ (after a fill-reducing reordering). It is computed once per precision matrix and shared by all operations on it. Iterative solvers such as conjugate gradients never factorize Q: they solve Qx=b using only products with Q, and so support fewer of the operations below. This page explains which operation each quantity needs, and which solvers provide it.

The operations ​

Solves. Conditioning on observations, and every Newton step of gaussian_approximation, needs solutions of Qx=b. With the factorization in hand, that is one forward and one backward triangular solve with L.

Log-determinants. logpdf needs log⁡detQ, which is free once Q is factorized: log⁡detQ=2∑ilog⁡Lii. The rest of the log-density is a sparse quadratic form. logdet_cov exposes the log-determinant of the covariance Q−1 directly.

Backward solves, for sampling. To draw x∼N(μ,Q−1), draw z∼N(0,I) and solve only the backward half, L⊤v=z, then set x=μ+v. This works because Cov(L−⊤z)=L−⊤L−1=Q−1. backward_solve performs this step.

Selected inversion, for marginal variances. var and std need the diagonal of Q−1. The full inverse is dense, but selected inversion (the Takahashi recursions) computes Q−1 only at the positions where L is nonzero. Those include the diagonal, and the cost is comparable to the factorization itself. See selinv.

Selected inversion, for gradients. The derivative of the log-determinant is ∂θlog⁡detQ=tr(Q−1∂θQ). Since ∂θQ has the sparsity pattern of Q, only the entries of Q−1 on that pattern are needed, and they are a subset of what selected inversion computes. This is why gradients of logpdf and logdetcov with respect to the precision require a solver that supports selected inversion; see Automatic Differentiation.

RBMC, when selected inversion is not available. Rao-Blackwellized Monte Carlo estimates marginal variances from samples, using the law of total variance:

Var(xi)=1Qii+Var(E[xi∣x−i]),E[xi∣x−i]=μi−1Qii∑j≠iQij(xj−μj).

The first term is exact; only the second is estimated from samples, which makes the estimate much less noisy than the plain sample variance. RBMCStrategy and BlockRBMCStrategy control the number of samples. The result is stochastic, so prefer selected inversion whenever the solver supports it.

Without a factorization there is no L, so iterative solvers can sample only when a square root of Q is supplied: they solve Qx=Qz, which has the right covariance. See Solvers for how to choose an algorithm.

Two GMRF types use their own factorization instead of a LinearSolve algorithm, and support all of the operations above:

  • ChordalGMRF factorizes with the multifrontal Cholesky from CliqueTrees.jl, including selected inversion.

  • WorkspaceGMRF factorizes through a reusable workspace, so that repeated factorizations of the same sparsity pattern share one symbolic analysis. See Workspaces.
